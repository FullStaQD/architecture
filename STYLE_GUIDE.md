# Style Guide
This documents summarises a few guidelines to use when writing our technical
documentation.
We keep this guide to a minimal set of guidelines that should improve the
consistency of our documentation.
These guidelines are not rules; you should generally follow them but you can and
should break them if that improves readability.
For more guidance on technical writing, have a look at prominent documentation
style guides like
[Google's documentation style guide](https://developers.google.com/style).

- We use **British English** for our documentation.
- We use [Excalidraw](https://excalidraw.com) for our diagrams.
  Elements of a diagram (e.g. meaning of boxes, lines or colours) should be
  explained in a legend.
